# Project instructions

- Keep every `docs/` directory local. Never stage, commit, push, or upload its contents, including in PRs, attachments, or published artifacts.
- Never stage, commit, push, or upload environment files, including `.env`, `.env.*`, `*.env`, `*.env.*`, `env`, `env.*`, and `.envrc` variants. This includes example and template environment files.
- Never use force-add or change ignore rules to bypass these restrictions. Check staged filenames before any commit and outgoing changes before any push.
- Collaborate with the user in Chinese. During requirements brainstorming, proactively confirm key workflow decisions and record confirmed decisions separately from proposals and open questions in local `docs/`.
